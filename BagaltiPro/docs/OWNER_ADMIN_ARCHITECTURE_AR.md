# فصل مالك التطبيق عن مالك المتجر

## قرار النسخة الحالية

تطبيق Android الحالي مخصص للتاجر ويخزن بياناته محلياً داخل قاعدة SQLite على الجهاز. لذلك لا يمكن لمالك التطبيق أن يفعّل اشتراك متجر من هاتفه أو يوقفه عن بُعد بمجرد إضافة شاشة محلية إلى هذه النسخة. الحسابات الموجودة على أجهزة مختلفة لا تشترك في قاعدة بيانات واحدة، ولا توجد خدمة مصادقة أو API أو قاعدة بيانات مركزية موصولة بها.

أُزيلت بوابة المالك المحلية القديمة من مسار تطبيق التاجر؛ كانت تعتمد على آلية دخول محلية ولا توفر صلاحيات أو سجلاً مركزياً صالحاً لإدارة اشتراكات المتاجر. لن تُعاد كميزة فعالة قبل وجود خادم موثوق. هذا يحافظ على الفصل المطلوب: **مالك المتجر** يدير متجره ومخزونه وعملاءه، و**مالك التطبيق** يدير الاشتراكات والحسابات عبر لوحة إدارة مستقلة.

## مسار التجديد المتاح للتاجر

تُظهر الإعدادات حالة الاشتراك وتاريخ الانتهاء، وتتيح للتاجر الاتصال أو المراسلة أو مشاركة طلب تجديد إلى الرقم `+967778228995`. لا يجمع التطبيق أموالاً ولا يفترض طريقة دفع؛ يحددها مالك التطبيق عند التواصل معه.

## ما يلزم لإنجاز لوحة مالك التطبيق

1. خدمة خلفية مركزية ومصادقة منفصلة للموظفين، مع MFA وسياسات أدوار وصلاحيات.
2. معرف متجر ثابت مستقل عن معرّف قاعدة SQLite المحلية، وربط آمن بين التطبيق والخادم.
3. لوحة ويب خاصة بالمالك تعرض البحث عن المتاجر، بيانات المتجر والمالك، الحالة، تاريخ الانتهاء، وسجل الاشتراكات.
4. إجراءات مقيّدة لتفعيل/تمديد/إيقاف/إعادة تفعيل اشتراك، مع سبب الإجراء واسم الموظف والتاريخ ومدة الخطة والسعر المدفوع اختيارياً.
5. سجل تدقيق لا يمكن للتاجر تعديله، وتنبيهات قرب انتهاء الاشتراك، وآلية مزامنة حالة الاشتراك للتطبيق.
6. حماية API، نسخ احتياطي، مراقبة، حدود محاولات، واسترجاع للحسابات.
7. سياسة للعمل دون اتصال: فترة سماح محددة وموقعة رقمياً، ثم مزامنة، بدلاً من الاعتماد على ساعة الجهاز وحدها.

## بيانات مطلوبة قبل التنفيذ الخلفي

اختيار الاستضافة وقاعدة البيانات، أسماء المستخدمين الإداريين وأدوارهم، سياسة مدة السماح، الباقات والأسعار التي يحددها المالك، آلية إثبات الدفع اليدوي، وسياسة التعامل مع الإيقاف والعمل دون اتصال. لا توجد حالياً تهيئة أو بيانات اعتماد لخدمة خلفية، لذلك لم تُنشأ لوحة الإدارة عن بُعد في هذه الحزمة.
