# بقالتي برو — Android POS

مشروع Android أصلي بلغة Java وواجهات XML. هذه حزمة تطوير أولية محسّنة لتدفقات المتجر الأساسية، وليست إصداراً إنتاجياً معتمداً.

## فتح المشروع وبناؤه

يتطلب المشروع Android Studio حديثاً، JDK 17، وAndroid SDK Platform 34، واتصالاً لتنزيل المكتبات عند أول بناء. المستودع يحتوي Gradle Wrapper 8.2.1 وAGP 8.2.2. لا تتضمن هذه الحزمة APK جاهزاً.

من مجلد المشروع:

```bash
chmod +x ./gradlew
./gradlew assembleDebug
```

يكون APK التجريبي عادةً في `app/build/outputs/apk/debug/app-debug.apk`. نفّذ Sync/Build واختبارات على محاكي وجهاز فعلي قبل الاستخدام التجاري.

## الوظائف الموجودة

تسجيل الدخول وإنشاء حساب محلي، إدارة المخزون ومسح الباركود في المبيعات وإضافة الصنف، نقطة بيع تحفظ الفاتورة وبنودها ومخزونها ودين العميل، العملاء والسداد وكشف الحساب، المرتجعات، سجل الفواتير، المصروفات والتقارير التراكمية، وإعدادات المتجر ومشاركة طلب التجديد إلى مالك التطبيق.

## إعدادات البناء الحالية

AGP 8.2.2 وGradle 8.2.1؛ `namespace` و`applicationId`: `com.grocery.pos`، و`compileSdk`: 34، و`minSdk`: 23، و`targetSdk`: 34. واجهة التطبيق عربية باتجاه RTL، والألوان الرئيسية زمردي/ذهبي/عاجي.
