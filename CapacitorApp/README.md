# بقالتي برو (Baqalaty Pro POS) 🛒

نظام متكامل لإدارة البقالات ونقاط البيع والمخزون وحسابات العملاء والديون، مصمم باللغة العربية (RTL) مع دعم الوضع الفاتح والداكن وتقارير إغلاق الوردية (Z-Report) والعمل بدون إنترنت.

---

## المميزات الأساسية
- **نقطة البيع السريعة (POS):** بيع بالكرتون والتجزئة، مسح الباركود، أزرار البيع السريع، تعليق الفواتير، والخصومات.
- **حسابات العملاء والديون:** سجل متكامل لكل زبون، سقف ائتمان، تنبيه تجاوز الحد، وإرسال كشف الحساب عبر WhatsApp.
- **المخزون والصلاحية:** تنبيهات قرب انتهاء الصلاحية، حد الطلب الأدنى، وحساب تكلفة الحبة تلقائياً من الكرتون.
- **تقرير إغلاق الدرج (Z-Report):** فرز دقيق للمقبوض نقداً، والمبيعات الآجلة (المتبقي دين)، والمرتجعات النقدية، وصافي الدرج.
- **الوضع الداكن والفاتح (Dark Mode):** مريح للعين ومتوفر في جميع الشاشات.
- **تطبيق أندرويد أصلي (Android APK):** مهيأ بالكامل عبر **Capacitor + Gradle + GitHub Actions**.

---

## طريقة بناء ملف APK تلقائياً عبر GitHub

1. ارفع هذا المشروع كاملاً إلى مستودع جديد في حسابك على **GitHub** (على الفرع `main` أو `master`).
2. انتقل في صفحتك على GitHub إلى تبويب **Actions**.
3. ستجد مهمة باسم **`Build Android APK (Baqalaty Pro)`** تعمل تلقائياً (كما يمكنك تشغيلها يدوياً من زر **Run workflow**).
4. بعد انتهاء البناء (حوالي دقيقتين)، انزل لأسفل الصفحة في قسم **Artifacts** وحمّل ملف:
   **`BaqalatyPro-Android-APK`**
5. فك الضغط لتحصل على ملف **`app-debug.apk`** جاهز للتثبيت على أي هاتف أندرويد ومشاركته مع المستخدمين!

## التشغيل المحلي للمطورين
```bash
npm install
npm run dev
```

لبناء مشروع الويب وتحديث مجلد أندرويد محلياً:
```bash
npm run build
npx cap sync android
```
